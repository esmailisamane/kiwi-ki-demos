# KIwi – KI-Demos

Code und echte Ergebnisse zu den **KI-News** und Einzelvideos vom YouTube-Kanal **KIwi – KI einfach erklärt**
(praktische KI für Entwickler).

Zu jedem Video gibt es einen eigenen Ordner mit einem kleinen, echten Experiment – kein reines Nacherzählen von News:

- der Code aus dem Video zum Selbst-Ausprobieren,
- `outputs/` mit den echten Ausgaben der Läufe, die im Video zu sehen sind,
- ein README mit Version, Datum und Quellen.

Alles läuft lokal; wo ein Modell nötig ist, steht es im jeweiligen README. Werkzeuge und Modelle ändern sich schnell –
prüfe immer die Version, mit der getestet wurde. Modellverhalten ist nicht vollständig deterministisch.
